# Privacy Policy

Last updated: 9 November 2026

Theo's YouTube Upload is a personal tool. It is used only by its owner, for his own YouTube channels.

It uses the YouTube Data API and the YouTube Analytics API to upload videos, to set titles, descriptions and thumbnails, and to read the statistics of the owner's own channels.

Access tokens are stored only on the owner's own computer. No data is sold, shared with third parties or used for advertising. No data from other people is collected.

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Access can be revoked at any time at https://myaccount.google.com/permissions
